# Contributing

Thanks for your interest in improving the Hyperlocal Heat-Risk Predictor.

## Getting started
1. Fork the repo and clone it locally.
2. Install dependencies: `pip3 install -r requirements.txt`
3. Run the app locally to confirm your environment works (see `run instructions.md`).

## Making changes
- Keep the project 100% local — no external API calls.
- Follow existing code style (PEP8 for Python).
- Add/adjust comments for any new model logic in `src/heat_model.py`.
- Test dashboard changes manually by running `python3 src/app.py`.

## Submitting
- Open a pull request with a clear description of the change and why it's needed.
- Reference any related issue numbers.
